# 名刺 PDF の置き場所

ここに次の2ファイルを置くと、サイトの Card セクションが表示されます。

| ファイル名 | 内容 |
| --- | --- |
| `front.pdf` | 名刺の表面 |
| `back.pdf` | 名刺の裏面 |

- **1ページ目だけ**を読み込みます。表裏を1つのPDFにまとめず、面ごとに分けてください。
- サイズは名刺の実寸（日本の標準は 91×55mm）で書き出してください。
  縦横比はPDFから読み取るので、変型サイズでもそのまま反映されます。
- 塗り足し（トンボ）は不要です。仕上がりサイズで書き出してください。
- 文字はアウトライン化しなくても構いません（PDF.js がフォントを描画します）。
  ただし特殊なフォントで崩れる場合は、アウトライン化すると確実です。
- 透過部分は白い紙として描画されます。

**2つとも揃っていない場合、Card セクションは自動的に非表示になります。**
片面だけ置いても表示されないのでご注意ください。

差し替えるときは、同じファイル名で上書きするだけです。
