# 名刺の置き場所

サイトの Card セクションが読むのは **WebP 画像** です。PDF は元データとして置いてあり、
ページ下部の「表 PDF / 裏 PDF」リンクからダウンロードできます。

| ファイル | 役割 |
| --- | --- |
| `front.webp` / `back.webp` | サイトが表示する画像（**これが無いとセクションは出ません**） |
| `front.pdf` / `back.pdf` | 元データ。画像の書き出し元と、ダウンロードリンク用 |

## 名刺を更新するとき

1. `front.pdf` と `back.pdf` を新しいものに差し替える
2. 変換スクリプトを走らせて WebP を作り直す

```
pip install pymupdf pillow
python3 tools/card-to-webp.py
```

3. できた `front.webp` / `back.webp` を含めてアップロードする

## PDF を書き出すときの注意

- **1ページ目だけ**を使います。表裏を1つのPDFにまとめず、面ごとに分けてください。
- 名刺の実寸（日本の標準は 91×55mm）で書き出してください。
  縦横比は画像から読み取るので、変型サイズでもそのまま反映されます。
- 塗り足し（トンボ）は不要です。仕上がりサイズで書き出してください。

## なぜ PDF を直接表示していないか

当初は PDF.js でブラウザ上に PDF を描画していましたが、この名刺に使われている
`FormaDJRMicro` というフォント（CFF 形式）の文字幅を PDF.js が正しく扱えず、
「Shimba Osuke」や URL の欧文が重なって潰れてしまいました。
PDF.js の v4・v5 いずれでも同じ症状が出たため、元の見た目を確実に保てる画像方式に変更しています。

この変更で、読み込むライブラリも 4.9MB から 0.75MB に減っています。
